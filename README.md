# GOST Flowchart Studio

Веб-приложение для генерации, интерактивного редактирования и экспорта блок-схем по ГОСТ 19.701-90 (ЕСПД).

Все необходимые библиотеки уже включены в репозиторий (`vendor/wheels`). Приложение работает сразу из коробки без ручного ввода команд установки и может запускаться полностью оффлайн без интернета.

## Запуск

### Linux / macOS
```bash
./run.sh
```

### Windows
Запустите `run.bat` двойным кликом или через консоль:
```cmd
run.bat
```

Скрипт автоматически настраивает окружение, выбирает случайный свободный порт и открывает приложение в браузере.

## Обновление библиотек (при желании)
Если потребуется обновить встроенные библиотеки до самых свежих версий из сети:
- Linux / macOS: `./update.sh`
- Windows: `update.bat`

## Требования
- Python 3.10+ (наличие `uv` опционально: приложение работает как с `uv`, так и со стандартным Python без сторонних пакетных менеджеров)
- Graphviz (`dot`) и `librsvg` (`rsvg-convert`)

## Возможности

1. **Генерация из кода:**
   - Поддерживает Python, C, C++, Pascal, Java, JavaScript, Go.
   - Распознает условия, циклы, ввод-вывод и подпрограммы.
   - Ошибки и исключения (`raise`, `assert`, `throw`) оформляются параллелограммом вывода диагностического сообщения с переходом в аварийный останов.

2. **Редактор:**
   - Свободное перемещение блоков (Drag and Drop), масштабирование и панорамирование.
   - Палитра всех символов ГОСТ 19.701-90 (процесс, условие, ввод-вывод, подпрограмма, документ, БД, подготовка, терминатор, соединитель).
   - Редактирование блоков: смена типа символа, редактирование текста, удаление.
   - Редактирование стрелок: клик по стрелке позволяет изменить подпись ветви («Да», «Нет»), выбрать точки подключения (порты сверху, снизу, слева, справа) или развернуть направление.
   - Автоматическое выравнивание по правилам ГОСТа.

3. **Горячие клавиши:**
   - `Ctrl + Z` — отмена последнего действия (Undo).
   - `Ctrl + Y` (или `Ctrl + Shift + Z`) — повтор действия (Redo).
   - `Delete` / `Backspace` — удаление выбранного блока или стрелки.
   - Двойной клик по блоку — редактирование текста на месте.
   - Двойной клик по стрелке — быстрое изменение подписи ветки.

4. **Экспорт:**
   - Экспортирует схему точно в таком виде, как вы её расставили на холсте.
   - PNG (300 DPI) с белым фоном блоков и контрастным текстом.
   - Векторный SVG.
   - Документ PDF для печати.
   - Graphviz DOT и JSON проекта (сохранение и загрузка).
