# GOST Flowchart Studio 📊

Кроссплатформенное интерактивное веб-приложение для автоматической генерации, визуального редактирования и экспорта блок-схем алгоритмов строго по **ГОСТ 19.701-90 (ИСО 5807-85)** (Единая система программной документации — ЕСПД).

---

## Возможности

1. **Генерация блок-схем из исходного кода:**
   - Поддерживает **Python** (через встроенный AST парсер), а также **C, C++, Pascal, Java, JS, Go** и псевдокод.
   - Распознает условия (`if/else`), циклы (`while`, `for`), вызовы функций, операции ввода/вывода (`print`, `cin`, `cout`).
   - Исключения и ошибки (`raise`, `throw`, `assert`) автоматически формируются через **параллелограмм ввода-вывода** с переходом в аварийный останов согласно ГОСТ.

2. **Интерактивный визуальный редактор (Flowchart Editor):**
   - **Холст:** свободное перемещение блоков (Drag & Drop), масштабирование (Zoom) и панорамирование (Pan).
   - **Палитра символов ГОСТ 19.701-90:**
     - 🛑 **Терминатор** («Начало» / «Конец» / «Выход»)
     - ⏹️ **Процесс** (вычисления, присваивания)
     - 🔶 **Решение** (ромб, ветвления условий)
     - ▱ **Данные / Ввод-вывод** (параллелограмм)
     - 📑 **Предопределенный процесс** (вызов подпрограммы с двойными боковыми границами)
     - 📜 **Документ** (печатный вывод с ГОСТовской волной снизу)
     - 🛢️ **Запоминающее устройство** (цилиндр БД / файл)
     - ⬡ **Подготовка** (шестиугольник цикла со счетчиком)
     - ⚪ **Соединитель** (разрыв линий на листе)
   - **Редактирование созданных блоков:**
     - Двойной клик по блоку — редактирование текста прямо на холсте.
     - Инспектор свойств справа — мгновенная смена типа блока (например, превращение процесса в подпрограмму), редактирование текста и подписей веток («Да» / «Нет»).
   - **Инструмент связей (Connect):** соединение блоков ортогональными стрелками.
   - **Автовыравнивание по ГОСТу:** автоматическое перестроение схемы с идеальным расположением блоков сверху вниз и слева направо.

3. **Экспорт в любые форматы:**
   - 📷 **PNG (300 DPI)** — полиграфическое качество для вставки в курсовые, отчеты и дипломы. Включает векторный клиппинг стрелок (стрелки никогда не заезжают за границы блоков) и волну для документов.
   - 📐 **SVG** — векторный формат без потери четкости.
   - 📄 **PDF** — готовый документ для печати.
   - 📝 **DOT** — исходный код Graphviz.
   - 💾 **JSON** — сохранение и открытие проекта.

## Быстрый старт

### Требования
- Python 3.10+
- [uv](https://github.com/astral-sh/uv) (менеджер пакетов Python)
- Graphviz (`dot`) и `librsvg` (`rsvg-convert`)

### Запуск

```bash
cd /home/zakat0v/gost-flowchart-web
./run.sh
```

Приложение автоматически откроется в браузере по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000).
